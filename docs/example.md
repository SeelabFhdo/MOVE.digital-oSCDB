(started with `docker compose -f compose.deploy.yaml up -d --build`, see [deployment.md](deployment.md)).

and can differ slightly between runs.

## Part 1: REST lookups

### 1. Which timetable is current?

`current` is the feed valid today. Today no feed covers the date, so OSCDB falls back to the latest feed and says so with `"fallback": true` (and the header `OSCDB-Feed-Fallback: true`).

```bash
curl -s http://localhost:8080/api/v1/feeds/current | jq
```

```json
{
  "id": 19,
  "sourceFile": "2026/140626_310826_gtfs_dsw21.zip",
  "startDate": "2026-06-14",
  "endDate": "2026-08-31",
  "version": "20260918 15:48:10",
  "status": "READY",
  "importedAt": "2026-10-27T08:55:42.618530Z",
  "fallback": true
}
```

## Part 2: Natural-language inquiries

Ask in plain language, choose `json`, `csv`, `xml` or `geojson`, then poll the job. See [inquiries.md](inquiries.md).

### 6. Inquiry: Top 5 busiest stations by number of departures on 2026-07-01

Submit the question with format `csv`. The answer is `202 Accepted` with the job id:

```bash
curl -s -X POST http://localhost:8080/api/v1/inquiries \
  -H 'Content-Type: application/json' \
  -d '{"question":"Top 5 busiest stations by number of departures on 2026-07-01","format":"csv"}'
```

```json
{"id":"77a9d386-bef7-406f-af9f-8b4eb939b42a","status":"QUEUED","queuePosition":1,...}
```

Poll the job until `status` is `DONE` (this one took 8 s). `meta` shows the generated SQL and every assumption:

```bash
curl -s http://localhost:8080/api/v1/inquiries/77a9d386-bef7-406f-af9f-8b4eb939b42a | jq '{status, error, meta: (.meta | {sql, assumptions, feeds, rowCount, truncated, attempts})}'
```

```json
{
  "status": "DONE",
  "error": null,
  "meta": {
    "sql": "select station_name, count(*) as departure_count from v_departure where feed_id = 19 and effective and service_date = date '2026-07-01' and not is_last_stop group by station_name order by departure_count desc limit 5",
    "assumptions": [
      "feed 19 is the current feed and valid on 2026-07-01",
      "busiest interpreted as most scheduled departures (excluding last stops where passengers cannot board)",
      "counting all departures per station name across all lines"
    ],
    "feeds": [
      19
    ],
    "rowCount": 5,
    "truncated": false,
    "attempts": 1
  }
}
```

Download the result:

```bash
curl -s http://localhost:8080/api/v1/inquiries/77a9d386-bef7-406f-af9f-8b4eb939b42a/result
```
